# About Me

Durable context about the user so you can work the way they prefer, without re-asking what they have already told you.

## How to use this skill

1. Read [profile.md](profile.md) — the profile of record.
2. Apply what's relevant: match their communication style, honor stated preferences and boundaries, and use their context to make better-tailored decisions and recommendations.
3. Do not re-ask for anything the profile already answers.

## Keeping the profile current

When the user states a new lasting preference, fact, or piece of context ("I prefer X", "I always Y", "from now on Z"), update the matching section of [profile.md](profile.md) so it persists across sessions. Record **durable** facts only — not one-off details specific to the current task.

## When the profile is thin

If [profile.md](profile.md) is largely empty, or a section marked _(unknown)_ is relevant to the current task, use the **ask-me** skill to interview the user and fill in the gaps rather than guessing.
